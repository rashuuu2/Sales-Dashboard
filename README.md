# 📊 Sales Performance Dashboard (Power BI)

An interactive **Sales Performance Dashboard** built using **Power BI**, designed to analyze sales targets, order trends, customer demographics, and team performance across multiple dimensions.

This dashboard helps stakeholders quickly understand **how sales teams, managers, and regions are performing against targets**, and where improvements are needed.

---

## 🚀 Project Overview

This project visualizes an e-commerce sales dataset to provide insights into:

- Sales performance vs targets  
- Team and manager-wise target achievement  
- Customer country and order source analysis  
- Monthly sales and order value trends  

The dashboard is fully interactive with slicers for **gender** and **order value**, allowing dynamic exploration of data.

---

## 📁 Dataset Description

The dataset contains transactional e-commerce sales data with the following key attributes:

- **Order Date & Time**
- **Order Value**
- **Customer Country**
- **Customer Gender**
- **Order Source** (App, Website, WhatsApp, Other)
- **Sales Team** (Alpha, Beta, Gamma, Delta, Epsilon)
- **Sales Manager**
- **Sales Target**
- **Target Status** (Met / Exceeded / Not Met)

---

## 📊 Dashboard Features & Visuals

### 🔹 Sales by POC Bucket
- Categorizes sales into:
  - Target Met
  - Target Exceeded
  - Target Not Met
- Helps identify overall performance distribution

### 🔹 Total Sales Target by Sales Team
- Compares total sales targets across teams
- Quickly highlights top and bottom performers

### 🔹 Sales Target % by Sales Manager and Team
- Visualizes how each sales manager performs against targets
- Segmented by sales teams for deeper insights

### 🔹 Monthly Sales Trend
- Line chart showing:
  - Sum of Order Value
  - Total Sales Target
- Useful for identifying seasonal patterns and gaps

### 🔹 Order Count by Country and Order Source
- Shows how customers place orders across countries
- Compares App, Website, WhatsApp, and Other sources

### 🔹 Total Sales Target by Customer Country and Sales Manager
- Multi-dimensional comparison of geography and leadership performance
